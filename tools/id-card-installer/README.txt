ID CARD READER SETUP  /  تجهيز قارئ بطاقة الهوية
=================================================

On each PC that reads Bahrain ID cards (Windows 10 or 11):

  1. Plug in the card reader.
  2. Double-click  Install.cmd  and approve the Windows prompt.
     Everything is inside this package: nothing is downloaded, no internet is needed.
  3. Put a Bahrain ID card in the reader and double-click  Check.cmd.
     It should end with "Everything is ready".
  4. In the system: open an employee, press "Read ID card".

  Undo.cmd puts back what Install.cmd replaced. install-log.txt records every step.
  The card's personal data is never shown or saved by these files.

على كل جهاز يقرأ بطاقات الهوية البحرينية (Windows 10 أو 11):

  1. وصّل قارئ البطاقة.
  2. انقر مرتين على  Install.cmd  ووافق على نافذة Windows.
     كل شيء داخل هذه الحزمة: لا يُنزَّل شيء ولا يحتاج إلى إنترنت.
  3. أدخل بطاقة هوية بحرينية وانقر مرتين على  Check.cmd، ويجب أن ينتهي بعبارة "Everything is ready".
  4. في النظام: افتح الموظف واضغط "Read ID card".
